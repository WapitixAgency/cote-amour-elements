# cote-amour-elements

Le guide du coureur de marathondelacotedamour.com (`guide-coureur`), servi par jsDelivr pour qu'un code
d'en-tête du site le définisse avant le runtime de Wix. Le même fichier est déjà servi publiquement par
Wix : rien ici n'est secret.

**Ne rien éditer ici.** Tout est produit par `cote-amour/outils/cdn.mjs` depuis
`src/public/custom-elements/guide-coureur.js`, à chaque push (action `livrer-cdn` du dépôt privé).
`r<révision>/` porte le fichier pour chaque révision publiée à venir du site.

Source : `WapitixAgency/cote-amour ac80c36`.
